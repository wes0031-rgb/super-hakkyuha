# 슈퍼 하뀨하 (SUPER HAKKYUHA)

Hearts2Hearts 공식 캐릭터 「하뀨하」로 달리는 오토런 플랫포머. 팬메이드 · 비매품.

플레이 → https://wes0031-rgb.github.io/super-hakkyuha/

## 조작
- Space · ↑ — 점프 (길게 누르면 높이, 공중에서 한 번 더 누르면 2단 점프)
- ↓ · Shift — 슬라이드
- 화면 오른쪽 절반 터치 점프 · 왼쪽 절반 터치 슬라이드

## 어떻게 하는 게임인가
캐릭터가 알아서 앞으로 달린다. 구멍을 뛰어넘고, 매달린 것은 슬라이드로 지나고,
슬라임은 밟고, 밤송이와 가시는 피한다. 끝까지 가면 스테이지 클리어.

스테이지를 깨면 그때 쓴 캐릭터가 펫으로 들어온다. 다섯 번째 먹구름성을 깨면
새장이 열리면서 쭈일리언을 구해 내고, 그때부터 쭈일리언을 데리고 다닐 수 있다.

진행은 브라우저에 저장된다.
